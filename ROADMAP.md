# Roadmap

This roadmap is directional and will evolve as VS Box Quantity Pricing is tested against real WooCommerce catalogue requirements.

## v0.1.x — Core box pricing

- [x] Simple products.
- [x] Variable products in the implementation design.
- [x] Product-level Units Per Box default.
- [x] Per-variation override/inheritance behaviour.
- [x] Per-unit catalogue/product price presentation design.
- [x] Box-price cart calculation design.
- [x] Cart/checkout unit information design.
- [x] Order-line fulfilment information design.
- [ ] Live WooCommerce installation testing.
- [ ] Tax configuration testing.
- [ ] Fixed-cart, fixed-product and percentage coupon testing.
- [ ] Cart and Checkout Blocks UX testing.

## v0.2.x — Merchant and storefront UX

- [ ] Configurable terminology: box, case, pack or custom label.
- [ ] Configurable frontend wording.
- [ ] Improved shop-loop presentation for variable products with mixed box sizes.
- [ ] Optional per-box price emphasis.
- [ ] Product list/admin indicators for box-priced products.

## v0.3.x — Pricing rules

- [ ] Box-based minimum and maximum purchase quantities.
- [ ] Box quantity price breaks / wholesale tiers.
- [ ] Optional minimum order value per product.
- [ ] Better sale-price messaging at unit and box level.

## v0.4.x — Integrations and developer API

- [ ] WooCommerce REST API exposure for Units Per Box.
- [ ] WooCommerce CSV import/export support.
- [ ] Public filters/actions for resolved units, unit prices and box prices.
- [ ] Compatibility testing with common B2B/wholesale plugins.
- [ ] Compatibility testing with subscriptions, bundles and composite products where appropriate.

## Future

- [ ] Reporting based on boxes and physical units.
- [ ] Optional stock management in individual units while selling in boxes.
- [ ] Bulk editing of box quantities.
